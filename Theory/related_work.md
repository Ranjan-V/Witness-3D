# Primary-source related-work matrix

Checked online 2026-11-02. Descriptions are short, selective paraphrases. Reported experiments below are authors' evidence, never results of this project. No inaccessible full text is represented as reviewed.

| Approach / verified source | Problem, technique and assumptions | Guarantee / evidence examined | Witness3D distinction and assessment |
|---|---|---|---|
| CARVE, Xu et al., 2026, [arXiv:2604.21713v1](https://arxiv.org/html/2604.21713v1) | Feed-forward multi-frame geometry; training-recipe ablation, depth/camera/pointmap consistency and high-resolution adaptation; learned data prior. | HTML method and experiment sections accessible; authors report reconstruction, video-depth and camera benchmarks. No input-wise infeasibility guarantee identified. | Explicit bounded-input verification and selective frozen-output repair differ in output contract. Merely adding multi-view consistency is not substantial. |
| Self-Geometry, Youn et al., 2026, [arXiv:2608.10708v1](https://arxiv.org/html/2608.10708v1) | Correspondence-supervised test-time adaptation; multi-view/epipolar losses, gradient disentanglement, angular-neighbor sampling, LoRA; reliable external matching. | HTML method, experiments and limitations examined. Reported tests span six model variants and four datasets; dependence on matching and latency acknowledged. No exact bounded-input contradiction certificate identified. | No model optimization, explicit abstention, independent depth attribution. Strong broad-motivation overlap; comparison is necessary, implementation equivalence not claimed. |
| UniCorrn, Goswami et al., 2026, [arXiv:2605.04044v1](https://arxiv.org/html/2605.04044v1) | Unified 2D/3D correspondence via modality backbones and a shared transformer with separate appearance/position streams; learned matching supervision. | HTML method and experiment layout examined; authors evaluate matching and registration. Matching confidence is not deterministic correctness. | Potential upstream matcher, not a depth-claim verification method. Substantive task difference, not a reason to claim better matching. |
| Kahl, 2005, [Multiple View Geometry and the L-infinity Norm](https://vision.ucsd.edu/publications/2005/multiple-view-geometry-and-l-infinity-norm) | Worst-case multiview geometric estimation with fixed or restricted camera parameters; convex/quasiconvex feasibility. | Official publication metadata accessed; full original proof not reviewed in this audit. | Polyhedral fixed-camera geometry is inherited. Robust union envelopes and selective repair need comparison, not relabeling. |
| Sim & Hartley, 2006, Removing Outliers Using the L-infinity Norm; [author tutorial containing citation and support-set/duality discussion](https://cs.adelaide.edu.au/~tjchin/tutorials/cvpr18/Part2.pdf) | Geometric outlier removal based on worst-case fitting and support information. | Search-index excerpt accessed; PDF fetch timed out. Original paper must be retrieved before a detailed guarantee comparison. | Direct threat to any claim about certificate-guided outlier localization. Distinction rests on individual depth claim envelopes and safe abstention, and remains unestablished. |
| DUSt3R, Wang et al., [arXiv:2312.14132](https://arxiv.org/abs/2312.14132), [CVF](https://openaccess.thecvf.com/content/CVPR2024/papers/Wang_DUSt3R_Geometric_3D_Vision_Made_Easy_CVPR_2024_paper.pdf) | Learned pairwise pointmaps and global alignment for uncalibrated reconstruction; image-trained prior. | Abstract/publication source accessed, not a code reproduction. Reconstruction evidence is empirical. | Fixed supplied cameras and verified inconsistency are narrower, different capabilities. Global point alignment is prior art. |
| VGGT, Wang et al., [arXiv:2503.11651](https://arxiv.org/abs/2503.11651), [CVF](https://openaccess.thecvf.com/content/CVPR2025/papers/Wang_VGGT_Visual_Geometry_Grounded_Transformer_CVPR_2025_paper.pdf) | Joint feed-forward prediction of geometry and cameras from images. | Abstract/publication source accessed. Learned predictions do not establish bounded-error premises. | Optional future upstream backbone; heavy models are not necessary for the CPU verifier. No model architecture novelty claimed. |
| Depth Anything V2, [arXiv:2406.09414](https://arxiv.org/abs/2406.09414), [official metric API](https://github.com/DepthAnything/Depth-Anything-V2/tree/main/metric_depth) | Frozen monocular depth, with separate relative and metric checkpoints; synthetic/real training pipeline. | Official README and metric dpt source inspected. Metric small uses a distinct model configuration and checkpoint. | An input source; relative output cannot be silently labeled metric. No pretrained interval coverage guarantee. |
| MiDaS, [official repository](https://github.com/isl-org/MiDaS), [small-model API](https://raw.githubusercontent.com/isl-org/MiDaS/master/hubconf.py) | Relative inverse depth with mixed-dataset training; compact v2.1-small variant. | Official API source inspected. Local loading without automatic checkpoint retrieval is possible. | Compact sensitivity control requiring disjoint geometry-only calibration; it does not satisfy the metric premise unaided. |
| Monodepth2, Godard et al., [ICCV 2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Godard_Digging_Into_Self-Supervised_Monocular_Depth_Estimation_ICCV_2019_paper.html) | Self-supervised depth via view synthesis, minimum reprojection, automasking and training design; scene/photometric assumptions. | CVF abstract and method excerpt accessed. Evidence is benchmark depth quality, not guaranteed correctness of an inference instance. | Verification and abstention differ; photometric/geometric self-supervision itself is established. |
| TEASER / TEASER++, Yang, Shi & Carlone, [arXiv:2001.07715](https://arxiv.org/abs/2001.07715) | Robust 3D registration using truncated least squares, graph invariants and certifiable rotation optimization; bounded inlier errors. | Abstract examined. Authors provide conditional estimation/optimality results and robust registration benchmarks. | Different unknowns (fixed-camera point/depth constraints); robustness and optimization certification are inherited concepts. |
| C-3PO, Talak, Peng & Carlone, [arXiv:2206.11215v4](https://arxiv.org/abs/2206.11215) | Object-pose estimation, observable correctness/non-degeneracy certificates, keypoint correction and certificate-guided self-training; object prior and partial point cloud. | Detailed abstract accessed; not a full theorem reproduction. Authors report pose experiments and conditional correctness framework. | Strong conceptual overlap. Sparse multi-view depth attribution with auxiliary-failure budgets is the specific proposed distinction; certification-plus-correction is not new. |
| SE-Sync, Rosen et al., [author publication](https://david-m-rosen.github.io/publication/sesync-wafr/) | Pose-graph synchronization via low-rank semidefinite relaxation; noise/model assumptions. | Author metadata and presentation accessed; conditional global-optimality certification, not physical-scene truth. | Supplied-camera feasibility differs from pose optimization. No claim to solve uncertain-pose certification. |
| Dellaert & Kaess, [Factor Graphs for Robot Perception, 2017](https://www.cs.cmu.edu/~kaess/pub/Dellaert17fnt.html) | Sparse factor-graph inference, elimination and incremental smoothing; selected residual/noise models. | Author summary accessed. Sparse computational structure is well established. | Global graph reconciler is a comparison/control; graph structure is not a contribution. |
| Chinneck, 1997, [doi:10.1287/ijoc.9.2.164](https://pubsonline.informs.org/doi/10.1287/ijoc.9.2.164) | Finding small irreducible infeasible subsystems in LP; deletion/filtering and optimization techniques. | Official abstract accessed; computational evidence reported by author. | Conflict extraction is inherited; minimal versus minimum must remain distinct. |
| Junker, 2004, [QuickXplain](https://ocs.aaai.org/Library/AAAI/2004/aaai04-027.php) | Preferred explanations and relaxations in monotone constraint systems, using divide-and-conquer and consistency queries. | Official abstract and indexed PDF excerpt accessed. Multiple conflicts/relaxations are already established. | A reference algorithm to compare for conflict extraction; this code uses explicit small search/deletion, not a claimed QuickXplain reproduction. |
| Clarke et al., 2000, Counterexample-Guided Abstraction Refinement, doi:10.1007/10722167_15; [author bibliography](https://www.cs.cmu.edu/~emc/papers.htm) | Verification through abstraction refinement guided by spurious counterexamples. | Bibliographic evidence accessed; original paper not fully reviewed. | Counterexample-guided terminology is inherited. Here refinement concerns depth claims/hypotheses, not a new program-verification principle. |
| Farkas alternatives, convex duality, Helly's theorem, interval/set-membership analysis | Classical finite-dimensional infeasibility, support bounds, convex intersection and conservative enclosures. | Mathematical statements and self-contained proofs/reductions in `Math/`; not presented as discoveries. | Only the particular vision decision protocol is proposed. A broader original-source survey remains necessary. |
| Fischler & Bolles, RANSAC (1981), doi:10.1145/358669.358692; Triggs et al., Bundle Adjustment (1999/2000), doi:10.1007/3-540-44480-7_21 | Consensus sampling and robust joint camera/point least squares; inlier/noise/initialization assumptions. | Classical reference identifiers; full articles were not fetched in this audit. Baselines use original generic implementations, not paper reproductions. | Essential comparisons; residual thresholds, robust triangulation and BA are not new. |

Uncertainty-calibration literature is only partially audited. In particular [WACV 2025 conformal extrinsic calibration](https://openaccess.thecvf.com/content/WACV2025/papers/Cocheteux_Uncertainty-Aware_Online_Extrinsic_Calibration_A_Conformal_Prediction_Approach_WACV_2025_paper.pdf) was identified but not reviewed deeply enough for a guarantee comparison. This gap prevents calling the audit complete.
